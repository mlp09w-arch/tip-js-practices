# ПР1. Первые программы на JavaScript

Из корня репозитория выполните `node practice-01/js/hello.js`. Так же запускаются `types.js`, `progress.js`, `plan.js` и `debug.js`.

Для запуска в браузере откройте `practice-01/index.html` и консоль разработчика. По умолчанию подключён `hello.js`. Для других заданий замените путь в теге `script` на нужный файл.
