# Контрольная работа № 1. Основы JavaScript

Решения четырёх заданий КР1 на основе ПР1–ПР3. Для запуска нужны Node.js 24 и браузер. Установка пакетов не требуется.

| Практика | Запуск из корня репозитория |
| --- | --- |
| ПР1 — сводка выполнения задач | `node practice-01/js/progress.js` |
| ПР2 — отбор и изменение статуса | `npm --prefix practice-02 start` |
| ПР3 — фильтрация и переключение статуса | `npm --prefix practice-03 start`, затем открыть `http://127.0.0.1:5503/` |

В ПР3 выберите фильтр «В работе» и нажмите «Выполнена» у задачи № 4. Останется задача № 7, а сводка покажет 4 задачи, 3 выполненные, 1 оставшуюся и прогресс 75.0%.

Проверки сервиса запускаются командами `npm --prefix practice-02 run check` и `npm --prefix practice-03 run check:service`. Браузерные проверки доступны на странице «Проверки» приложения.

[Отчёт КР1](КР1.docx) содержит листинги и четыре скриншота фактических запусков.
